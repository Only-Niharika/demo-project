# Demo Project

This is a simple demo project built using **HTML**, **CSS**, and **JavaScript**.

## Description

The project contains a basic student portal login system. It uses a default username and password to demonstrate simple form validation with JavaScript.

After a successful login, the user is redirected to the dashboard page.

## Default Login Details

```text
Username: test
Password: 12345 
```

## Files Included

demo-project/
│
├── index.html
├── dashboard.html
├── style.css

## Features

Simple login page
Basic username and password validation
Dashboard page after successful login
Separate HTML, CSS, and JavaScript files
Clean and simple user interface

## How to Run

Download or clone the project.
Open index.html in a web browser.
Enter the default username and password.
Click Login to access the dashboard.

## Note

This project is for learning and demonstration purposes only. It does not use a database or secure authentication.
